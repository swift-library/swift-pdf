# Changelog

## Unreleased

- **Breaking**: Require Swift 6.3 or later (Xcode 26.6 or later), with deployment
  minimums of iOS 18, macOS 15, and visionOS 2.

## 0.1.1

- Preserve a successor viewer’s proxy commands when the outgoing viewer detaches.
- Publish cached search results and focused index when output bindings are replaced.

## 0.1.0

- Display PDFKit documents, PDF data, and file URLs in SwiftUI on iOS, macOS, and visionOS.
- Navigate pages, control zoom, and select search results through a viewer proxy.
- Publish settled page, scale, and search state through bindings.
- Attach SwiftUI page overlays with lifecycle release callbacks.
- Provide a PDFViewer example and documentation for viewing, overlays, and search.
